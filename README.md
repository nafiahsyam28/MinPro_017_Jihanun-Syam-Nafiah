# Penjelasan Program
Program ini dibuat guna mengelola ataupun membantu sistem administrasi di dalam Rumah Sakit Hewan, contohnya seperti :
1. Menambah data pasien hewan
2. Melihat data pasien hewan
3. Mengubah data pasien hewan
4. Menghapus data pasien hewan <br>

Dengan adanya program ini, sistem administrasi rumah sakit hewan bisa terstruktur dengan rapi sehingga memudahkan bagi pengguna maupun pihak rumah sakit
